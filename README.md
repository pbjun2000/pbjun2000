# 안녕하세요, 백엔드 개발자를 준비하고 있는 박병준입니다.

Java와 Spring Boot 기반의 REST API 개발을 중심으로 학습하고 있습니다.  
프로젝트에서는 API 응답 DTO 분리, 전역 예외 처리, Postman 기반 API 테스트,  
AWS 기반 CI/CD 및 CloudWatch 모니터링 흐름을 정리했습니다.

<br/>

## 🔧 Tech Stack

### Backend
Java, Spring Boot, Spring Data JPA, REST API, MySQL, H2

### DevOps / Cloud
AWS CodeBuild, Amazon ECR, Amazon EKS, CloudWatch, Docker, Kubernetes

### Tools
Git, GitHub, Postman

<br/>

## 📌 Featured Projects

### 📚 AI Book Service

React 기반 도서관리 서비스를 Spring Boot 백엔드 API로 전환한 팀 프로젝트입니다.

- Entity 직접 반환 문제를 DTO 응답 구조 분리로 개선
- `GlobalExceptionHandler` 기반 전역 예외 처리 구조 적용
- Postman 기반 API 성공/실패 케이스 테스트
- H2 Console을 활용한 샘플 데이터 저장 상태 확인

🔗 GitHub: https://github.com/pbjun2000/aivle-ai-book-service-review

<br/>

### ☁️ BookService AWS CI/CD & Monitoring

React + Spring Boot 서비스를 AWS 기반 CI/CD 파이프라인과 EKS 배포 환경으로 연결한 프로젝트입니다.

- CodeBuild, ECR, EKS 기반 배포 흐름 정리
- Kubernetes `deployment.yaml`, `service.yaml` 작성 및 검증 참여
- CloudWatch Dashboard 구성
- EC2, CodeBuild, Logs, EKS, ELB 지표 기반 운영 상태 확인

🔗 GitHub: https://github.com/pbjun2000/aivle-book-service-aws-review
